HOW TO DEPLOY THE SAPAPNJ BACKEND API
======================================

What changed:
- cloud_functions/api/routes/users.js — Added GET /api/users/:uid/comments endpoint

This is the backend API running on Google Cloud Run.
You only need to redeploy when backend files (cloud_functions/api/) are changed.
Flutter-only changes do NOT require this deployment.


DEPLOYMENT STEPS
================

1. Open a terminal (PowerShell, CMD, or Git Bash)

2. Navigate to the API folder:
   cd cloud_functions/api

3. Make sure you are authenticated with Google Cloud:
   gcloud auth login

4. Make sure your project is set correctly:
   gcloud config set project YOUR_GCP_PROJECT_ID

5. Deploy to Cloud Run:
   gcloud run deploy sapapnjapi --region=asia-southeast2 --source=. --allow-unauthenticated

6. Wait for the build and deployment to finish (usually 2-5 minutes).

7. Done! The new endpoint will be live at your Cloud Run URL.


ALTERNATIVE: Using the deploy script (Git Bash / Linux / macOS only)
====================================================================

From the project root:
   bash cloud_functions/api/deploy.sh


VERIFYING THE DEPLOYMENT
=========================

After deploying, test the new endpoint:
   curl -H "Authorization: Bearer YOUR_FIREBASE_TOKEN" https://YOUR_CLOUD_RUN_URL/api/users/SOME_USER_UID/comments

You should get a JSON array of comments (or an empty array [] if the user has no comments).
