HOW TO DEPLOY THE SAPAPNJ BACKEND API (via GCP Cloud Shell)
============================================================

What changed:
- cloud_functions/api/routes/users.js — Added GET /api/users/:uid/comments endpoint

This is the backend API running on Google Cloud Run.
You only need to redeploy when backend files (cloud_functions/api/) are changed.
Flutter-only changes do NOT require this deployment.


DEPLOYMENT STEPS
================

1. Push your latest code to GitHub first:
   git push

2. Open GCP Cloud Shell:
   https://shell.cloud.google.com

3. Clone or pull the repo in Cloud Shell:

   First time:
     git clone https://github.com/YOUR_USERNAME/SapaPNJ.git
     cd SapaPNJ

   Already cloned before:
     cd SapaPNJ
     git pull

4. Navigate to the API folder:
   cd cloud_functions/api

5. Deploy to Cloud Run:
   gcloud run deploy sapapnjapi --region=asia-southeast2 --source=. --allow-unauthenticated

6. If prompted to select a project, choose your GCP project.
   If prompted to enable APIs, type Y.

7. Wait for the build and deployment to finish (usually 2-5 minutes).

8. Done! The new endpoint will be live at your Cloud Run URL.


VERIFYING THE DEPLOYMENT
=========================

In Cloud Shell, test:
   curl https://YOUR_CLOUD_RUN_URL/api/health

You should get: {"status":"ok","timestamp":"..."}
